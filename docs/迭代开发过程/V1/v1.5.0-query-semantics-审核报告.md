| 测试用例 | 覆盖 |
|---------|------|

| null 字段 + 其他操作符 → 不匹配 | null 语义规范 |
| between [low, high] 闭区间含边界 | 范围过滤 |

| mode: default 区分大小写（回归） | 向后兼容 |
| mode: insensitive + startsWith/endsWith | 大小写不敏感 |

| containsAll 数组字段匹配全部值 | 数组字段（compareValues） |
| containsAny 非数组字段 → false | 类型处理 |
