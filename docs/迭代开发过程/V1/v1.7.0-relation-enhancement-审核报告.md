## 三、测试覆盖明细

| 测试用例 | 覆盖 |
|---------|------|
| insert 自动更新 inverse hasMany FK 数组 | 双向同步（belongsTo→hasMany） |
| insert hasMany 父行同步子行 belongsTo FK | 双向同步（hasMany→belongsTo） |
| update FK 变更时旧值移除 + 新值追加 | 双向同步（disassociate+associate） |
| remove 时清理 inverse hasMany FK 数组 | 双向同步（remove 级联） |
| 无 inverse 字段时无同步 | 向后兼容 |
| count 基本计数 | 聚合过滤 |
| sum/avg/max/min 数值计算 | 聚合过滤 |
| filter 先过滤后聚合 | 聚合过滤 |
| where + per-field filter 为 AND | 聚合过滤 |
