## 五、方案审查改进项（Oracle 4🔴+4🟡）落地情况

| # | 问题 | 方案修订 | 落地 |
|---|------|---------|------|
| 🔴1 | Date 映射缺 number 时间戳 | `z.union([z.iso.datetime(), z.date(), z.number()])` | ✅ `zod.ts:44` |
| 🔴2 | enum 不处理 number 枚举值 | 全 string → `z.enum`；含 number → `z.union(z.literal)` | ✅ `zod.ts:56-63` |
| 🔴3 | selfHealing 冗余 `zodSchema` 字段 | 删除，迁移后默认已受益 | ✅ `ai/index.ts:55` 签名不变 |
| 🔴4 | codegen 静态导入强制装 zod | 改为动态 import + try/catch 友好错误 | ✅ `templates.ts:203-215` |
| 🟡1 | 空 enum 降级比旧行为严格 | 文档标注 + `z.union([z.string(), z.number()])` 宽松放行 | ✅ |
| 🟡2 | .d.ts 暴露 zod 类型 | `ValidateIssue` 自定义类型替代 `z.ZodIssue` | ✅ |
| 🟡3 | 无缓存 | `WeakMap<MockFieldSchema, z.ZodType>` | ✅ |
| 🟡4 | 数组路径 `$[0]` 格式兼容 | `formatPath` 导出复用 | ✅ |
